Smart Irrigation System

Designing and programming an automated watering system for a snake plant using real-time soil-moisture readings, a relay-controlled water pump, and plant-specific watering logic.

Role: Independent designer & builderArduino UnoSoil-moisture sensingRelay & pump control

01 / Project overview

I developed this personal project to automate plant watering while accounting for the needs of a particular plant. Instead of relying on a fixed calendar schedule, I built a system that reads soil conditions and uses those readings to decide when to activate a small water pump.

The project combined physical prototyping, circuit assembly, Arduino programming, and threshold selection. I built the setup independently, connecting the Arduino Uno to a moisture sensor, relay module, pump, tubing, and water reservoir.

02 / System design

The system is a basic feedback controller: it measures a physical condition, compares that measurement with a programmed threshold, and changes an output in response. The moisture sensor supplies an analog reading to the Arduino; the Arduino uses conditional logic to control the relay; and the relay switches the pump circuit.

01 / SENSE

Measure soil conditions

A soil-moisture sensor provides analog values that the Arduino can monitor.

02 / DECIDE

Compare with threshold

The program compares the reading with a selected value of 500 to determine whether watering is needed.

03 / ACTUATE

Control the relay

The Arduino sends a digital signal to the relay module, allowing it to switch the pump.

04 / DELIVER

Water the plant

When activated, the pump transfers water from the reservoir through tubing toward the plant.

03 / Programming and automation

I programmed the Arduino Uno to read moisture data and apply conditional logic. The Arduino IDE screenshot shows the program printing sensor readings to the Serial Monitor and checking the value against the threshold of 500.

sensor1Value = analogRead(Pin1);
Serial.println(sensor1Value);

if (sensor1Value > 500) {
  digitalWrite(IN1, LOW);
} else {
  digitalWrite(IN1, HIGH);
}

In this wiring configuration, the LOW output is used to activate the relay when the reading exceeds 500; HIGH is used otherwise. This is a raw sensor threshold, not a percentage of soil moisture, so its interpretation depends on the particular sensor and setup.

04 / The engineering challenge: setting the threshold

The most difficult part of this project was choosing the moisture threshold. I designed the system for a snake plant, which tolerates relatively dry soil and generally needs less frequent watering than many common houseplants. My goal was to avoid activating the pump too early and overwatering the plant.

I selected a threshold of 500 for my particular sensor setup to allow the soil to remain relatively dry before the system triggered watering. This meant translating the plant's needs into a numerical decision rule rather than simply running the pump on a timer.

The experience demonstrated an important engineering principle: automated systems need settings tailored to the application. A threshold that works for one plant or sensor may not work for another without recalibration.

05 / Testing and observations

The Serial Monitor gave me a way to observe real-time readings and check whether the control logic was responding to the sensor input. I used these readings to evaluate the programmed threshold and how the relay would respond as the measured soil conditions changed.

My prototype demonstrates the integration of sensing, software decisions, and physical actuation. The photos document the assembled hardware and the programmed logic; they do not establish long-term watering performance or water savings, so I have not claimed either.

06 / Skills and takeaways

Technical skills

Arduino C/C++ programming, analog sensor input, conditional logic, relay control, breadboard wiring, pump integration, and prototyping.

Engineering lessons

Matching system behavior to real-world requirements, calibrating control thresholds, troubleshooting connected hardware and software, and using measured data to inform design decisions.
